## Source of truth
- `docs/srs/` is the only business source of truth.
- Technical, planning, research, and archive docs must not redefine product scope.

## Current layout
- `srs/` — business requirements, flows, traceability, and UI/spec docs
- `api/` — API reference and developer-facing endpoint docs (kept in place)
- `technical/` — architecture, backend, standards, and RAG notes
- `operations/` — runbooks and deployment instructions
- `planning/` — delivery roadmaps and non-canonical plans
- `research/` — raw evidence and supporting artifacts
- `archive/` — historical or superseded material
